FFR or IVUS to Guide PCI

FLAVOUR Trial (NEJM 2022) Journal Review

Taehee Shin

Glossary

  • CAD(Coronary Artery Disease): Coronary Artery(관상동맥)이 plaque(죽상판) 축적으로 좁아지는 질병
  • Ischemia: 허혈. CAD로 인해 심장 근육에 혈액 공급이 부족해지는 상태
  • PCI(Percutaneous Coronary Intervention): 이를 stent나 풍선으로 넓혀주는 시술. 경피적 관상동맥 중재술
  • Revascularization: 재혈관화. 좁아지거나 막힌 혈관으로 인해 피가 통하지 않는 부위에 혈류를 다시 회복시키는 치료법

Glossary

  • FFR(Fractional Flow Reserve): 협착이 실제로 혈류를 막아 ischemia를 유발하는지 보는 생리학적 검사
  • IVUS(Intravascular Ultrasonography): 혈관 구조와 스텐트 설치 상태를 보는 형태학적 영상 검사. 혈관 내 초음파
  • CAG(Coronary Angiography): 조영제로 혈관을 찍는 표준 기본 검사
  • Intermediate stenosis: CAG상 협착 40~70%, PCI 여부 판단이 애매한 구간

Background

  • CAG: 협착이 70% 이상 → PCI, 40% 이하 → 약물치료

  • Intermediate Stenosis(40-70%)에서 PCI 여부 결정 어려움

  • FFR: 허혈 예측에 강함. “허혈을 일으키는가”

  • IVUS: 스텐트 설치 가이드에 강함. “스텐트가 잘 들어갔는가”

  • 두 방법 head-to-head 비교 연구 부재 → FLAVOUR trial

Major Protocol Revision

  • 원래 목적(2016.7): FFR 우월성(superiority) 입증

  • 시작 이후, IVUS 유리하다는 연구들 발표 → 비열등성(noninferiority)으로 변경(2017.6)

  • 사전 공개 변경. 실제 데이터 확인 전에 이뤄짐 ## Method — 연구 설계

  • Investigator-initiated

  • Prospective

  • Randomized

  • Open-label

  • Multinational(한/중 18개 기관)

  • Noninferiority trial

Method — 대상

  • 19세 이상의 intermediate stenosis 발견 & 표적혈관 직경이 2.5mm 이상인 저위험군 환자 대상

  • 약물 과민성, 출혈 위험, 기대여명 2년 이내 등은 제외

  • FFR군 vs. IVUS군 1:1 랜덤 배정

  • 당뇨 유무로 statified

Method — PCI 기준

FFR군 IVUS군
PCI 시행 FFR ≤ 0.80 MLA(최소내강면적)) ≤3mm² 또는 3~4mm² & plaque>70%
PCI 성공 시술 후 FFR ≥0.88 또는 stent 양끝 FFR차 <0.05 plaque≤55% & MSA≥5.5mm²

Endpoint

  • Primary: POCO(Patient-Oriented Composite Outcome) = Death + Myocardial Infarction(MI) + Revascularization (24개월)
  • Secondary: Primary + stent 개수 + 뇌졸중 + 환자결과보고서(SAQ)

통계방법론

비열등성 시험이란?

  • 일반적인 임상시험(Superiority trial): “A가 B보다 낫다”

  • 해당 연구(Noninferiority): “A가 B보다 크게 나쁘지 않다”를 증명

  • FFR은 스텐트/자원 소모가 적음 → 효과가 동등하거나 약간 못해도 여전히 임상적 가치가 있음

  • Margin 2.5%p = “이 정도 차이는 임상적으로 무시 가능”하다고 사전에 합의한 기준선 → 다소 주관적, 논쟁 지점

  • FFR군의 사건 발생률이 IVUS군보다 2.5%p 이상 높지만 않으면 비열등하다고 인정

Power

  • Power(검정력): 실제로 차이가 있을 때 그 차이를 통계적으로 잡아낼 확률. Reject H0 when H1 is true
  • FFR군 사건 발생률 10% vs. IVUS군 12% (가정)
  • 90% 검정력 확보 → 1700명 필요 → 최종적으로 1682명 등록(FFR 838명, IVUS 844명)
  • (참고: 최초 프로토콜의 superiority 설계 당시 계획 표본은 4400명 → noninferiority로 전환 후 margin·가정 event rate이 바뀌며 1700명으로 축소)

Statistical Analysis

  • 범주형 변수 비교 → Chi-square test
  • 연속형 변수 비교 → T-test
  • Primary endpoint → Log-rank test + Cox proportional-hazards regression 병행
    • Log-rank: 두 Kaplan-Meier 곡선 자체를 비모수적으로 비교
    • Cox: site, 당뇨 유무를 보정한 회귀모형으로 HR 산출
    • 두 방법이 유사한 결론을 내는지 교차 확인하는 역할

Kaplan-Meier & Cox model

  • Kaplan-Meier: 시간에 따라 특정 사건 없이 생존한 비율을 보여주는 계단식 그래프. 중도탈락(censoring) 환자도 정보 손실 없이 반영
  • Cox 비례위험모형: 그룹 간 사건 발생 위험을 시간에 따라 비교, 결과값 = Hazard Ratio(HR)
    • HR 0.96 → FFR군 위험이 IVUS군 대비 4% 낮음(거의 동일)
    • 연구 기관(site), 당뇨 유무를 random effect로 보정

비례위험 가정 검증

  • Cox 모형: “HR이 시간 내내 일정하게 유지”된다는 전제 위에서만 성립
  • Schoenfeld residual test로 확인 → P=0.99 (가정 위반 근거 없음)

비열등성 판정 방법

  • 차이(FFR−IVUS) = −0.4%p
  • 1-sided 95% CI 상한 = 1.8%p (< 2.5%p) → 통과
  • 1-sided 97.5% CI 상한 = 2.2%p (< 2.5%p) → 더 보수적 기준으로도 통과

1종 오류율 설정 - 왜 단측(1-sided) 5%인가

  • 표준적인 noninferiority trial: 단측 2.5%(양측 5%에 대응) 사용이 관행
  • 해당 연구: 단측 5.0% 사용 → 사실상 양측 10%에 해당하는 더 관대한 기준
  • 저자 근거: 의료기기 평가에서 종종 쓰이는 관행적 기준
  • 보완: 더 보수적인 단측 97.5% CI(=단측 2.5%에 해당)도 함께 보고

ITT vs Per-protocol

  • ITT(Intention-to-Treat): 처음 배정된 군 그대로 분석. 중간에 프로토콜을 어겼거나 실제도 다르게 치료받은 환자도 배정된 군으로 계산 → 무작위 배정의 장점 유지
    • 표준적 1차 분석법 (주 분석)
  • Per-protocol: 프로토콜 잘 지킨 환자만 남겨 분석 (민감도 분석으로 병행)
  • 두 결과 거의 동일 (8.1% vs 8.5% / 8.2% vs 8.7%) → 결과 신뢰도↑

결측치 처리

  • Endpoint 결측치는 제거(complete case analysis)
  • 민감도 분석으로 결측치의 영향을 별도 확인
  • 실제 follow-up 완료율 99.2% (14명만 손실) → 결측 자체가 결과에 미친 영향은 제한적

Multiplicity Problem

  • Multiplicity(다중비교): 한 연구에서 여러 개의 2차 outcome(개별 사망률, MI 등)을 동시 검정 → 우연히 유의미해 보이는 결과가 나올 확률↑
  • 저자 스스로 multiplicity 보정 안 했다고 명시
  • → 2차 outcome CI는 확정적 근거 아님, 가설 생성용으로만 해석해야

Results

Baseline 특성

  • 두 군의 평균 연령, 당뇨병 유병률 등 기본 특성이 잘 균형잡혀 있음

PCI 시행률

  • lesion 길이, 혈관 직경, 협착 정도는 유의한 차이 x
  • FFR 44.4% vs IVUS 65.3% (기준이 다르므로 당연)
  • 다만 실제로 시술받은 환자 내 스텐트 개수/길이는 유사

Primary & Secondary Outcomes

  • Primary:
    • FFR 8.1% vs IVUS 8.5%, HR 0.96
    • 비열등성 마진(2.5%p) 이내 → noninferior(P=0.01)
  • Secondary:
    • 당뇨 유무, ITT vs Per-protocol 분석법 차이 모두 결과에 영향 x
    • PCI 성공률도 유의한 차이 x(50.1% vs 54.8%)
    • 프로토콜에 명시된 adenosine 대신 nicorandil 사용한 288 제외한 사후분석(post hoc)에서도 일관된 결과

Limitations

  • Open-label: 시술자가 배정군 인지 → revascularization 여부 결정에 영향 가능
  • 두 군의 PCI 시행/성공 기준 자체가 다름 → 순수 head-to-head 비교인지 애매
    • IVUS군의 PCI 시행률이 유독 높았던 것: IVUS 자체의 우수성 x, 현재 IVUS의 기준이 상대적으로 느슨
  • Noninferiority margin 2.5%p의 임상적 정당성 논쟁
  • 2차 outcome 다중비교 미보정

Limitations

  • 연구대상: 저위험군(SYNTAX<10)만 포함, 전원 아시아인 → 일반화 제한
  • Plaque의 성상(characteristics)은 PCI 기준에 반영되지 않음
  • FFR/IVUS 외 nonhyperemic pressure ratio, OCT, NIRS-IVUS 등과의 비교는 없음
  • FFR+IVUS 병용군이 연구에 없어, 두 검사를 함께 쓰는 전략의 효과는 확인 불가

Correspondence

  • “PCI 하고 싶으면 IVUS, 하기 싫으면 FFR 잰다” → 검사 선택 자체가 이미 시술자의 의도 반영(현실적 문제)
  • IVUS군 사망률이 더 높음(1.3% vs 2.3%) - 출혈이 원인 아닌가?
    • 다중비교 미보정 상태의 secondary outcome이라 과대해석 주의
    • 저자: 출혈은 실제로 더 있었으나, 원래 출혈 위험군에서 발생
  • ACS(급성관상동맥증후군) 1 환자 따로 subgroup 분석 요청 → 저자: 큰 차이 없음(10.0% vs 10.3%)

  1. 연구 대상의 약 30%. FFR은 원래 안정형 관상동맥질환에서 검증된 지표

Take-home Message

  • Intermediate stenosis 환자에서 FFR-guided는 IVUS-guided 대비 비열등, 스텐트는 유의하게 적게 사용
  • 우열 문제라기보다 상호보완적 도구로 해석
  • 통계적으로 꼼꼼하나(Schoenfeld 검증, ITT+PP 이중 확인) open-label/margin 설정은 해석 시 유의
